# PathAI

*Your Personal AI-powered Guide for Career Orientation & Daily Productivity*

</div>

## About The Project

**PathAI** is a comprehensive mobile and web application equipped with an AI management system designed to assist users in selecting university programs, achieving professional orientation, providing an AI study assistant, and generating personalized daily study plans. 

With both a React Native (Expo) frontend and a Node.js + Express backend powered by MongoDB and the DeepSeek AI API, PathAI gives students everything they need to manage their future.

## Features
- **AI Chatbot**: Get real-time advice and study help.
- **Career Assessment**: Find the best career paths suited to your traits.
- **Personalized Daily Planner**: Organizes your study schedule optimally.
- **Study Programs Tracking**: Discover university programs tailored to you.

---

## Built With

### Frontend (Client)
- **Framework**: [React Native](https://reactnative.dev/) / [Expo](https://expo.dev/)
- **Styling/UI**: React Navigation, Expo Vector Icons

### Backend (Server)
- **Runtime**: [Node.js](https://nodejs.org/en/)
- **Framework**: Express.js
- **Database**: [MongoDB](https://www.mongodb.com/) (Mongoose)
- **AI Integration**: DeepSeek API
- **Auth**: JWT & bcrypt

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn
- MongoDB (Local or Atlas URI)
- DeepSeek API Key

### Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/UMMustafa23/PathAI.git
   cd PathAI
   ```

2. **Start the Backend Server**
   ```bash
   cd server
   npm install
   # Create a .env file with your PORT, MONGO_URI, and DEEPSEEK_API_KEY
   npm start
   ```

3. **Start the Frontend App**
   Open a new terminal window:
   ```bash
   cd client
   npm install
   npx expo start
   ```
